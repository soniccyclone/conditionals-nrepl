* Decision register
** DONE D3. Interrupt of a CPU-bound eval
Decided by Nathan on 2026-10-11: forced stop is the primary mechanism, mirroring the JVM's =interrupt-stop= (interrupt, wait 5 s, kill). The CLR kill primitive is =System.Runtime.ControlledExecution.Run= (=TH5=, =TH6=, =TH7=), driven by a re-interrupt plus =Cancel= from a dedicated reaper thread. Only an opt-out key =:force-interrupt= (default true). Spec in [[file:03-design.org::*Interrupt policy (D3, decided: forced stop is primary)][03-design §Interrupt policy]].

* Risks
| Id | Risk | Likelihood | Mitigation |
|---+---+---+---|
| R1 | Upstream rejects host seams as scope creep | medium | D15 (b); PRs 1, 1b, 3, 2 are unconditional wins; seams arrive with a green CLR branch and a bencode benchmark |
| R2 | A forced stop lands inside user code that holds a lock or a half-updated structure; on the CLR a user =catch Exception= handler runs during the abort, a loop that never leaves a =catch= / =finally= cannot be stopped, and an undeliverable abort parks the reaper thread in =Cancel= (=TH6=, =TH7=) | medium | same exposure class as JVM =Thread.stop=; documented in the =interrupt= op; =:force-interrupt false= opt-out |
| R4 | =Thread.Interrupt= consumed by a user =catch= (=TH3=) or lost inside an STM lock wait (=TH8=; the body itself propagates it) | low | the 5 s forced stop is the backstop, exactly as on the JVM |
| R6 | Windows: PEM private keys unusable by SChannel | certain | PFX round-trip in slice 16; TLS tests already skipped on Windows upstream |
| R7 | Culture-sensitive string operations on the CLR: ClojureCLR's own =clojure.string= prefix/suffix/search functions and =sort= on strings are culture-sensitive (=B9=) | certain if ported naively | PR 2's helper block with =StringComparison/Ordinal= branches in slice 13; =DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1= documented as a user-side mitigation |
| R8 | =clj-kondo= cannot lint =:cljr= branches (hard error if the feature is configured, =J5=) | certain | =:cljc {:features [:clj]}=; CLR branch coverage comes from the CLR suite executed with =*warn-on-reflection*= as errors |
| R9 | ClojureCLR 1.13 changes break assumptions | low in 2026 | pin 1.12.6; CI also runs =1.13.0-alpha= as allowed-failure |
| R10 | Core load on net8 is 2.5 s (=A10=) and AOT is unavailable on net8 builds (=A5=) | certain | document; AOT through a net9+ =Clojure.Main= build step for deployments (slice 19) |
| R11 | Test harness is the hidden cost (matcher shim, process spawning, cert generator, 24 test files to gate) | certain | slice 9 budgets 1.5 d with the per-file gating tables in the roadmap |
| R12 | Rendezvous relaxation changes backpressure | low | =make-rendezvous= on =Monitor= (=C7=) keeps zero-capacity semantics; =rendezvous-backpressure= test pins it |
| R13 | =StackOverflowException= is uncatchable on .NET: an unbounded recursion kills the process where the JVM survives | certain | document in the CLR section; out of scope to guard |
| R14 | =ControlledExecution.Run= overhead per exec | low | one delegate plus a =CancellationTokenSource= per exec; measure in slice 11 |
| R15 | Silent runtime failures on the CLR: missing members compile with only a reflection warning (=B2=, =E9=, =L5=), the 1-arg =Write= resolves to a =Span= overload (=E2=), =RT/classForName "[B"= returns nil (=L5=) | certain without a gate | CLR CI treats reflection warnings in =nrepl.*= as errors and executes every code path (not just =require=) |

* NOGO
- Inline =#?= as the strategy for =transport=, =completion=, =tls=, =cmdline= (single-expression sites listed in 03-design are the exception, not the rule).
- =.cljr= override files for shared logic under =src/clojure= (siblings are allowed only for =socket=, =tls=, =cmdline= where nothing is shared).
- A cooperative-only interrupt (D3).
- =random-uuid=, =parse-long= or any other Clojure 1.11+ core function in shared code: nREPL supports 1.10.
- Rewriting nREPL as a C# server.
- Any game-engine, editor-host or main-thread-dispatch feature in the library.
