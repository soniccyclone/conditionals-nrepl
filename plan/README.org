* Summary
Convert =src/clojure/nrepl/**.clj= to =.cljc= with =#?(:clj … :cljr …)= and a thin set of host seams (=nrepl.host.*=) so one tree yields a full nREPL on ClojureCLR 1.12.6 inside a Godot 4 (.NET 8) C# project. JVM behaviour is preserved and each refactor is shaped as an upstreamable PR you submit by hand. CLJS and jank are kept possible by the seam rules and otherwise untouched.
- 68 files, 9 702 LOC audited; 1 089 host-coupled sites; 21 files need a seam, 15 need a few inline conditionals, 11 rename as-is, 9 Java classes need =proxy=/C# replacements, 12 artifacts are JVM-only.
- Estimated 22–29 person-days across 4 phases; first CIDER connection to Godot after phase 2 (≈15–19 d).
- Hard facts that shape it: =:cljr= feature and =.cljr > .cljc > .clj= load order; =[ThreadStatic]= bindings; no =Thread.Abort= on .NET 8+ (=ControlledExecution.Run= is the only forced abort); Godot scene tree is main-thread-only; the editor's collectible ALC fights long-lived threads and dynamic assemblies.
