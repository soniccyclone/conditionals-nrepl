#+TITLE: 4. Subsystem plans: options, trade-offs, defaults
#+OPTIONS: ^:nil toc:2

Each subsystem lists the JVM shape, the CLR options, a default, and the decision id (see 06) when the user must choose.

* 4.1 Threads, executors, interrupt   (D1, D2, D3)
JVM: 5 cached daemon pools + =SessionThread= per session + =interrupt-stop= (interrupt, then =Thread.stop=/JVMTI after 5 s).
| Concern | Option | Trade-off |
|---+---+---|
| Loop threads (accept, per-connection handle, transport reader, session loop) | dedicated =Thread= =IsBackground=true=, named | only choice that keeps =Interrupt= targetable and avoids =ThreadPool= starvation shared with Godot |
| Short tasks (=handle*=, stream callbacks, ephemeral evals) | a. =ThreadPool.QueueUserWorkItem= b. =Task.Run= c. dedicated single consumer thread + =BlockingCollection= | a/b lose ordering of =:out= chunks (JVM cached pool also has none); c restores order, costs one thread per transport |
| =run-with= contract | returns a handle =(cancel! h)= → =Interrupt= on the owned thread | requires owning the thread, i.e. not =Task.Run= |
| Reaper (=schedule-once!=) | =System.Threading.Timer= (pool, may overlap) or a dedicated reaper thread with =Monitor.Wait(ms)= | timer is cheaper; reaper thread is reentrancy-safe |
| Interrupt of an idle/blocked session | =Thread.Interrupt= wakes =BlockingCollection.Take= and =Monitor= waits; fires =ThreadInterruptedException= | works; exception type differs; STM swallows it; catching consumes it |
| Interrupt of CPU-bound eval | D3 options: (a) cooperative only: bind =*cancel*= =CancellationToken= per exec, document =(nrepl.cancel/check!)= for user loops; abandon the thread, spawn a fresh session thread, report =:interrupted= (zombie keeps a core); (b) =ControlledExecution.Run= around the eval body: real abort, documented as unsafe, cannot abort native frames/=finally=; (c) patch ClojureCLR to poll a token in =recur=/=loop= (true cooperative-by-compiler, invasive, upstream ClojureCLR work); (d) out-of-process eval (not in scope) | default: (a) now + (b) behind =:force-interrupt? true= config, off by default |
| =describe= | add =:aux {:host {:name "clr" :can-stop-threads false}}= and =:versions {:clr …}= keeping =:java= absent | lets clients hide forced interrupt |
| Stack size | =Thread(ThreadStart, maxStackSize)= knob in =:thread-opts= | Godot threads default 1 MB on Windows |
| Classloader plumbing | =nrepl.host.clr.loader= no-ops; =with-session-classloader= expands to =do= | =AssemblyLoadContext= is per-assembly, not per-thread; see 4.8 for Godot ALC |

* 4.2 Sessions, eval, stdin   (D4, D6)
JVM: =session-exec= loop on =SessionThread=; =QueuePollingReader= for =*in*=; bindings pushed per message.
| Concern | Plan |
|---+---|
| Session loop | identical algorithm on a dedicated background =Thread=; =[exec-id r ack msg]= from =make-queue=; =r= invoked as =IFn=; catch =ThreadInterruptedException= where JVM catches =InterruptedException= |
| =*in*= | =nrepl.host.clr.io/stdin-reader=: =(proxy [System.IO.TextReader] …)= with =Read()=, =Read(char[],int,int)= (return 0 at EOF, not -1), =Peek= (needed because =TextReader= has no =ready()=), wrapped in =LineNumberingTextReader=; EOF sentinel must be a private object, not an interned string |
| =skip-stdin-newline= | =(.ready *in*)= → =(not= -1 (.Peek *in*))= under =:cljr=; verify =LineNumberingTextReader= forwards =Peek= |
| =gather-initial-bindings= | diff the var list against ClojureCLR =clojure.main/with-bindings=; =*compile-path*= from =CLOJURE_COMPILE_PATH= env instead of =System/getProperty= |
| =set-column!= reflection hack | =GetField "_columnNumber" NonPublic= on =LineNumberingTextReader= (prior art =cnrepl/interruptible_eval.clj:31=) |
| =:ex= / =:root-ex= strings | D6: (a) emit =(str (class e))= raw → ="System.ArgumentException"=; (b) emulate ="class …"= prefix for client regexes. Default (a); tests use =#?= expected values |
| Godot main-thread eval | D4: =:exec-fn= hook on the session (third variant beside persistent/ephemeral). Options: (a) =Dispatcher.SynchronizationContext.Send= per thunk: simplest, blocks session thread until next frame, eval runs with bindings pushed on main (must push/pop there), uninterruptible, long evals stall the game; (b) =Post= + promise: same but session thread is free to answer =interrupt= with "cannot interrupt main-thread eval"; (c) per-message opt-in =:main-thread true= slot, default off, so tooling evals stay off the main thread. Default: (c) with (b) mechanics, exposed as =nrepl.godot/main-thread-exec= in the Node repo, library only provides the hook |
| =*e= / =caught= | =Throwable= → =Exception= via one =#?= in =caught= fn; =StackOverflowException= uncatchable: document |

* 4.3 Output: print, io, out   (D5)
JVM: =PrintWriter= → =OutputStreamWriter= → =CallbackBufferedOutputStream= (bytes); =QuotaBoundWriter= throws =Error=; =TeeOutputStream= on =System.out=.
| Concern | Plan |
|---+---|
| =replying-PrintWriter= | one char-based =TextWriter= (=proxy= or C#, D5) buffering UTF-16, flushing on =\n= or =buffer-size=; must never throw into user code (swallow transport failures, record them) |
| Quota | =quota-writer= returns ={:writer :exceeded?}=; =wrap-print= checks the flag after =print-fn= returns; on JVM keep =QuotaExceeded= (behaviour preserved), on CLR flag only |
| =with-open= / close ordering | =Dispose(bool)= must flush synchronously before the outer catch sends =::truncated= |
| =forward-system-output= | =Console.SetOut/SetError= tee; add =unwrap-standard-streams= (also fixes the JVM leak); Godot: optional =OS.AddLogger= (4.5+, unverified) to tee =GD.Print= |
| Root =*out*= on CLR bypasses =Console.Out= | tee must also =alter-var-root= =*out*=/=*err*= as JVM does; both paths needed |
| Charset | CLR path has no bytes→chars round trip; fixes the latent default-charset bug at =print.clj:67= as a side effect |

* 4.4 Wire: bencode and transport
| Concern | Plan |
|---+---|
| Byte source | =nrepl.host.io=: =read-byte= (=ReadByte= → -1 at EOF, portable), =read-bytes= (loop on =Read= until =n= or 0 ⇒ EOF), =unread=, =write-byte!=, =write-bytes!=, =utf8-bytes=, =utf8-string=; bencode becomes =.cljc= with zero inline =#?= after the seam |
| Pushback | ClojureCLR =clojure.lang.PushbackInputStream= (1 byte; its zero-length base read can block on =NetworkStream=) or own =deftype= over =Stream= with a buffered inner stream. Default: own =deftype= over =BufferedStream= |
| Numbers | =BencodeSerializable= extended on =System.Int64 Int32 Int16 Byte SByte UInt16 UInt32 UInt64 BigInteger clojure.lang.BigInt= under =:cljr=; or =integer?= dispatch in =Object= fallback on both (behaviour-neutral) |
| Errors | replace message-string matching (=transport.clj:108-115=) with =ex-info= =:nrepl/kind= on both platforms; =SocketException(String)= impossible on .NET → =IOException= |
| Reader loop | =run-thread!= + =cancel!=; shutdown = close socket (unblocks =Read=) + cancel; loop exits on =ObjectDisposedException=/=IOException= instead of =Thread/interrupted= |
| Rendezvous | =make-rendezvous=: =Monitor=-based 1-slot handoff (fix the =cnrepl= =TryEnter=/=Exit= bug) or accept =BlockingCollection(1)= (reader may run one message ahead; only visible in tests) |
| Timeouts | clamp =Long/MAX_VALUE= to =Timeout.Infinite=; =TryTake(out T, int)= wrapped in the seam (by-ref syntax) |
| =Closeable= | =FnTransport= and =Server= implement =IDisposable=/=Dispose= under =:cljr= via =#?@= in the =deftype=/=defrecord= body; call sites use =(host/close! x)= |
| EDN / TTY transports | =PushbackTextReader= over =StreamReader=; TTY is =:clj=-first (Godot has no tty) |

* 4.5 Sockets, Unix sockets, TLS   (D7)
| Concern | Plan |
|---+---|
| Connection value | =nrepl.host.net= returns ={:socket :in :out :tls? :unix?}=; transport-fns take it; =Connectable=/=Acceptable= protocols extend the record. JVM impl keeps today's classes inside the record |
| TCP | =TcpListener= (=Socket.Listen= explicit), =Dns.GetHostAddresses= for =--bind localhost=; do not set =ReuseAddress= on Unix |
| Unix | =UnixDomainSocketEndPoint=, =AddressFamily.Unix=; one impl replaces =jdk17=/=junixsocket=; =unix-domain-flavor= → =:dotnet= |
| Accept loop exit | =TcpListener.Stop= → =SocketException=/=ObjectDisposedException= as the =ClosedChannelException= analog |
| TLS | D7: (a) port now with =SslStream=, =CreateFromPem=, PFX round-trip on Windows, custom-root =X509Chain=, =SslProtocols.None=; (b) =:cljr= stub that throws =::tls-unsupported= and ship later. Default (b) for the Godot milestone, (a) in phase 4 |
| =tls_client_proxy= | =:clj=-only until TLS lands |
| URI line | build the =nREPL server started on port %d on host %s - %s= string by hand on both hosts; drop =java.net.URI= from the shared path |

* 4.6 Reflection: completion, lookup, load-file   (D8)
| Concern | Plan |
|---+---|
| Pre-step on JVM (zero behaviour change) | replace ~40 =System.String= calls with =clojure.string= ordinal fns; replace =java.util= scratch collections with transients; both make =util/completion= mostly pure |
| =nrepl.host.reflect= | =members-of type= → ={:name :kind(:method :field :property :event :ctor) :static?}=; =type-name= spelling (nested =A+B=, generics =List`1=) D8; =keyword-table= seam (=Keyword._symKeyMap .Values= on CLR, Arcadia =autocompletion.clj:90=) |
| Classpath scan | CLR sources: =AssemblyLoadContext.All= types (guard =ReflectionTypeLoadException=), =CLOJURE_LOAD_PATH= walk for =.clj*=, AOT dll resources; Godot game assembly ALC included |
| =lookup= | =ns-resolve= returns nil on CLR for unknown dotted symbols: =:lookup-error= path becomes ={:info nil}=; accept and test with =#?= |
| =load-file= | =Compiler= vars: default = NonPublic reflection at load for =MethodVar NextLocalNumVar LoopLocalsVar= with graceful skip; file a ClojureCLR issue to make them public; =Compiler/load= 4-arg form |
| =:file= metadata | CLR gives absolute OS paths; =handle-file-meta= skips =io/resource= under =:cljr= |
