* Cross-cutting concerns (consolidated from 134 audit findings)
** Bytes and streams
- Java =byte[]= is signed, ClojureCLR =byte-array= is =System.Byte[]= (0–255). =bencode.clj:97= narrows via =unchecked-byte=; on CLR keep raw 0–255 ints. Fixture literals in =bencode_test.clj:186-192= are negative and must become =(bit-and x 0xFF)=.
- EOF contract: =InputStream.read(byte[],off,len)= returns -1, =Stream.Read= returns 0. =bencode.clj:102-104= =(neg? result)= spins forever on CLR; must be =(zero? result)=. Single-byte =read()=/=ReadByte()= agree (-1).
- No =PushbackInputStream= on .NET. One new host type: a 1-byte pushback over =Stream= (=deftype= with =^:unsynchronized-mutable=, or C#). Text side maps to =clojure.lang.PushbackTextReader= / =LineNumberingTextReader= (ClojureCLR =Readers/=).
- =OutputStream.write(int)= / =write(byte[])= → =Stream.WriteByte(byte)= / =Write(buf,0,len)=; the =ReadOnlySpan= overload confuses reflective resolution, so call the 3-arg form explicitly. 9 sites in =bencode.clj=.
- UTF-8: =StandardCharsets/UTF_8=, =.getBytes "UTF-8"=, =(String. b "UTF-8")= → =Encoding.UTF8.GetBytes/GetString=, 10 sites, 2 helper fns cover all.
- =extend-protocol BencodeSerializable java.lang.Number= (=bencode.clj:366=) has no CLR analog; .NET numerics are unrelated structs. Extend per type or dispatch on =integer?= in the =Object= fallback.
- =clojure.java.io= → =clojure.clr.io=: =reader/writer= are =text-reader/text-writer=; no =resource= (no classpath); =as-file= yields =FileInfo=; no =IOFactory= over =Socket= (build =NetworkStream= by hand); =edn/read= on CLR requires a =PushbackTextReader=.
** Exceptions and names
- =Throwable= does not resolve on ClojureCLR (only =System.*= auto-imported). 13+ sites in src plus macros =log-exceptions= / =safe-handle=: one =#?= in each macro fixes all expansions.
- =.getMessage= → =ex-message= (portable since 1.10, calls =.Message= on CLR). =safe-handle= (=transport.clj:261-283=) currently leaks =.getMessage= into every middleware error path; on CLR the error path itself throws. Fix once.
- =java.net.SocketException(String)= cannot be constructed on .NET (int error code only): the four disconnection throws in =transport.clj= need =IOException= or =ex-info= with =:nrepl/kind=.
- Disconnection detection matches exact exception message strings from =bencode.clj= and =clojure.edn= (=transport.clj:108-115=). Replace by =ex-info= kinds on both platforms.
- Map: =EOFException→EndOfStreamException=, =IllegalArgumentException→ArgumentException=, =IllegalStateException→InvalidOperationException=, =InterruptedException→ThreadInterruptedException=, =ClosedChannelException→ObjectDisposedException=, =URISyntaxException→UriFormatException=, =NoSuchMethodException→null from GetMethod=, =ThreadDeath→none=.
- Wire-visible =:ex= / =:root-ex= are =(str (class e))=: ="class java.lang.X"= on JVM vs ="System.X"= on CLR. Tests and some clients match on these.
- Uncatchable on .NET: =StackOverflowException=, =AccessViolationException=. A user eval of unbounded recursion kills the Godot process where JVM nREPL survives.
- =format= / =printf=: ClojureCLR =clojure.core/format= calls =clojure.lang.Printf/Format= with Java-style =%d/%s= specifiers (=Clojure.Source/clojure/core.clj:5978-5984=), so existing format strings port unchanged. One audit agent assumed =String.Format= semantics; that was wrong. =String.format= called directly as a Java static (=DaemonThreadFactory.java:22=) is the only real site.
** Threads, interrupt, executors
- =Thread.interrupt= on JVM = sticky pollable flag + =InterruptedException= from blocking ops. =Thread.Interrupt= on .NET = no flag; only wakes =WaitSleepJoin= (=Sleep/Join/Monitor/BlockingCollection.Take=); never unblocks =Stream.Read=. Sites: =threading.clj:86=, =transport.clj:59,62,67=, =session.clj:223=, =core_test.clj:507=.
- Forced stop impossible: =Thread.Abort= throws =PlatformNotSupportedException= on .NET Core 3+/5+. =threading.clj try-stop-thread=, =jvmti.clj=, =JvmtiAgent=, =nrepl_agent.c=, =jvmti_test.clj=, =core_test non-interruptible-stop-thread= collapse to one CLR behaviour. See decision D3.
- Executors: =listen=, =transport=, =handle=, =thread-reaper=, =ephemeral-executor= are cached pools from =DaemonThreadFactory=. Three workloads are infinite blocking loops (accept =server.clj:234=, per-connection handle =server.clj:80=, reader =transport.clj:58=) and must not go on the shared =ThreadPool= (Godot shares it; starvation). Dedicated =Thread IsBackground=true= or =TaskCreationOptions.LongRunning=.
- =run-with= deliberately does not convey bindings (=cmdline.clj:153= "just don't use future"); session uses explicit =push-thread-bindings=. ClojureCLR Var frames are =[ThreadStatic]= (=Var.cs:177=), identical model, provided execution stays on a real thread (no =async/await= hops).
- =SynchronousQueue= (zero capacity) has no .NET equivalent: =BlockingCollection(1)= lets the reader run one message ahead; =Channel.CreateBounded(1)= closest; =clr.tools.nrepl= hand-rolled =sync_channel.clj= with =AutoResetEvent= pairs.
- =BlockingQueue.poll(long, TimeUnit)= → =BlockingCollection.TryTake(out T, int)=: =out= parameter needs ClojureCLR by-ref syntax (wrap in helper); =Long/MAX_VALUE= ms overflows =Int32= (=core.clj:17=, =transport.clj=, tests) → clamp to =Timeout.Infinite=.
- Clojure fns are not delegates on CLR: =(Thread. f)=, =(reify Runnable)=, =.submit= need =(gen-delegate ThreadStart [] …)= / =sys-action=. =^Runnable= hints and =.run= in =session.clj= / =interruptible_eval.clj= become plain =IFn= invocation.
- =Thread$State/TERMINATED= equality → =.NET ThreadState= is a flags enum; use =Thread.IsAlive=.
- Daemon → =IsBackground=true=. Load-bearing in Godot: foreground threads keep the process alive and pin the editor's collectible =AssemblyLoadContext=.
** Classloaders
- =DynamicClassLoader=, context classloader, =Compiler/LOADER= (=misc.clj:92-98=, =session.clj:128-131,212=, =classloader.clj=, =DaemonThreadFactory=, =SessionThread=, 4 =core_test= tests) have no CLR analog. ClojureCLR compiles into never-unloaded dynamic assemblies. Nearest concept: =AssemblyLoadContext= + =CurrentContextualReflectionContext=. All of it is =jvm-only= under =:cljr=.
- =Compiler/eval= is =eval(Object, boolean freshLoader)= on JVM, =eval(object)= on CLR (=Compiler.cs:1229=).
- =load_file.clj:26-29= binds =Compiler/LOADER=, =METHOD=, =LOCAL_ENV=, =LOOP_LOCALS=, =NEXT_LOCAL_NUM=; on CLR =MethodVar=, =NextLocalNumVar=, =LoopLocalsVar= are =internal= (=Compiler.cs:206-210=). Options: NonPublic reflection, upstream ClojureCLR visibility change, or drop the bindings on CLR.
** Sockets, TLS, URIs
- JVM encodes TLS and Unix-ness in socket subtypes and dispatches with =instance?= (=socket.clj:100,106,119-132=). .NET: one =Socket= class (=AddressFamily.Unix= vs =InterNetwork=), TLS is =SslStream= layered over =NetworkStream=. The accept → transport-fn handoff needs a host-neutral connection value (socket + in + out + tls?).
- The =java.nio= channel/stream split and the JDK-4509080 =BufferedOutputChannel= workaround (=socket.clj:145-189=) are JVM-only. =jdk17= / =junixsocket= flavours collapse to =UnixDomainSocketEndPoint= (Linux, macOS, Windows 10 1803+).
- Semantics: =ServerSocket.bind= implies listen, .NET needs =Listen(backlog)=; Java =isConnected= is sticky-true, =Socket.Connected= reflects last I/O; no =isClosed=; =InetSocketAddress(String,int)= resolves names, =IPAddress.Parse= does not (=--bind localhost= needs =Dns.GetHostAddresses=); =NetworkStream= failures arrive as =IOException= wrapping =SocketException= (=server.clj:87= catch and 4 test assertions).
- TLS: JSSE =KeyStore/KeyManagerFactory/SSLContext= → =PemEncoding.Find=, =X509Certificate2.CreateFromPem=, =CopyWithPrivateKey=, =X509Chain= with =CustomRootTrust=, =Ssl{Server,Client}AuthenticationOptions= + validation callback. Windows Schannel wants a PFX round-trip for PEM keys; EdDSA keys unsupported in BCL; =(?m)$= regex differs on CRLF. PEM scanning and error messages (=tls.clj:84-149,263-292=) are pure. TLS tests already skipped on Windows.
- =java.net.URI= 3-arg opaque (=nrepl+unix:/path=) and 7-arg ctors plus =.toASCIIString= (=cmdline.clj:636=) have no faithful =System.Uri= equivalent; .NET normalizes unknown schemes. Build the CIDER-parsed line ="nREPL server started on port %d on host %s - %s"= by hand.
** Writers and output capture
- JVM =*out*= chain: =PrintWriter= → =OutputStreamWriter= (platform default charset, latent mojibake at =print.clj:67=, =out.clj:94-95=) → =CallbackBufferedOutputStream= (UTF-8). CLR: one char-based =TextWriter=. Buffer semantics change from bytes to UTF-16 units.
- =with-open= calls =.close= on JVM, =.Dispose= on CLR. =FnTransport= and =Server= must implement =IDisposable= under =:cljr=; interface and method name both conditional → =#?@= splice or a =defclose= helper macro. =print.clj:81= relies on close → flush → callback ordering before the outer =catch QuotaExceeded=.
- =System/setOut= and =bindRoot= of =*out*= are process-global and never undone; no unwrap exists. In Godot an unwrap hook on =AssemblyLoadContext.Unloading= is required or the old assembly cannot unload.
- Line separators: =System/lineSeparator= → =Environment.NewLine=; flush-on-=\n= still works for CRLF.
** Reflection, completion, lookup
- No classpath. CLR sources: loaded assemblies (=AppDomain.CurrentDomain.GetAssemblies()= / =AssemblyLoadContext.All=, guard =ReflectionTypeLoadException=), =CLOJURE_LOAD_PATH= dirs, AOT =*.clj.dll= + embedded resources, and the Godot game assembly in its own ALC.
- Object model: =Class→Type=, =getName→FullName= (nested =A+B=, generics =List`1=), =getPackage→Namespace=, plus =GetProperties/GetEvents= (properties dominate CLR members; =get_X/set_X= accessors flagged =IsSpecialName= must be filtered). New candidate kinds: =:property=, =:event=.
- ~40 =System.String= calls in =util/completion.clj= are culture-sensitive on .NET (=StartsWith/EndsWith/IndexOf=; Godot sets =CurrentCulture= from the OS). Rewrite with =clojure.string= ordinal fns first, on JVM, zero behaviour change.
- =Keyword.table= (JVM) vs =Keyword._symKeyMap= (CLR, not enumerable, use =.Values= → =WeakReference.Target=); Arcadia =autocompletion.clj:90-101= is working prior art. =ns-resolve= returns =nil= on CLR for unknown dotted symbols instead of throwing =ClassNotFoundException= (=util/lookup.clj:26= observable change).
- =io/resource= consumers: =version.clj= (artifact version) and =misc/handle-file-meta= (CIDER navigation); CLR var =:file= holds an absolute OS path or =NO_SOURCE_PATH=.
** Process, env, config
- =System/exit= (4 sites), =shutdown-agents=, =(.join (Thread/currentThread))=, =deleteOnExit=, =sun.misc.Signal= have no safe analog inside Godot; the engine owns lifecycle (=SceneTree.Quit=, =_ExitTree=). Needs an injectable =nrepl.host.process=.
- =System/getProperty= is a compile error on CLR (=System= is a namespace): =java.version=, =java.specification.version=, =jdk.attach.allowAttachSelf=, =nrepl.version=, =user.home=, test =nrepl.basedir=. → =Environment.Version=, =RuntimeInformation=, =Environment.GetFolderPath=, =AppContext.GetData=.
- =config.clj= is 100% filesystem/env (=~/.nrepl/nrepl.edn=, =.nrepl.edn=, env var); in exported Godot games CWD and =~= may be meaningless; a =res://= or =ProjectSettings= source is an option.
- =describe= reports =:versions {:nrepl :clojure :java}=; CIDER labels the third "Java". Decide =:java= with .NET info vs new =:clr= / =:host= key; =nrepl.spec= already allows any keyword.
** Tests
- =nubank/matcher-combinators= (=is+= everywhere) has no CLR port. =test_helpers.clj= uses =com.hypirion.io Pipe=, =Runtime/exec=, =java.net.ServerSocket=. =kaocha= is JVM-only. =com.github.ivarref/locksmith= (cert generator) is JVM-only. =test.check= needs the =clr.test.check= port.
- =core_test.clj= (1068 LOC, 58 sites) encodes JVM interrupt/classloader/exception-text behaviour; 4 tests are inherently JVM-only. =cmdline_test= spawns =java -cp … nrepl.main= subprocesses.
- Coverage gaps worth closing before porting: =nrepl.util.print= has no tests; =forward-system-output= has no op-level test; =caught= has no dedicated test.
