* .NET 8–10 threading and IO
| Fact | Consequence | Source |
|---+---+---|
| =Thread.Abort/Suspend/Resume= throw =PlatformNotSupportedException= (SYSLIB0006), by design, no replacement | nREPL's forced stop is gone | dotnet docs =thread-abort-obsolete= |
| =System.Runtime.ControlledExecution.Run(Action, CancellationToken)= (.NET 7+) is the only non-cooperative in-process abort; documented as dangerous, may corrupt state, cannot abort native frames or =finally= | the one real "kill the eval" option; only usable if the whole eval body runs inside it | dotnet docs =ControlledExecution= |
| =Thread.Interrupt= only wakes =WaitSleepJoin= (=Monitor=, =WaitHandle=, =Sleep=, =Join=, =SemaphoreSlim=); no pollable flag; never unblocks a synchronous socket read; catching the exception consumes it | cooperative cancellation needs a token; blocked reads need =Socket.Dispose= | dotnet docs, =SocketPal.Unix= |
| =Socket.Dispose= from another thread is the supported way to abort a blocked =Receive= (=ConnectionAborted= / =ObjectDisposedException=) | transport reader shutdown = close the socket | dotnet runtime |
| =NetworkStream.Read= returns 0 at EOF; =ReadAsync(Memory, token)= honours cancellation | async read path is the clean cancellable one | docs |
| =BlockingCollection= needs capacity ≥ 1; =Channel.CreateBounded(1)=; no zero-capacity rendezvous | =SynchronousQueue= semantics must be hand-built or relaxed | docs |
| =TcpListener.Stop= disposes the socket; pending =Accept= throws =SocketException= | accept loop exit path | docs |
| =SO_REUSEADDR=: .NET Unix PAL already sets it on TCP listeners; setting it again is harmful on Linux/macOS per refuter | do not port =setReuseAddress= blindly | refuter 12 |
| Unix sockets: =UnixDomainSocketEndPoint= on Linux/macOS/Windows 10 1803+; file deleted on =Dispose= | one implementation replaces jdk17 + junixsocket | docs |
| TLS: =SslStream= over =NetworkStream=; =X509Certificate2.CreateFromPem=; on Windows SChannel needs a PFX round-trip for PEM keys; prefer =SslProtocols.None= over pinning 1.3; no EdDSA in BCL | TLS is the costliest subsystem to port; TLS tests already skipped on Windows upstream | docs |
| =Guid.NewGuid= string == Java UUID v4 string format | wire ids compatible | docs |
| =Console.SetOut= is process-wide via =TextWriter.Synchronized= | tee is global, same as JVM | docs |
| =System.Threading.Timer= callbacks run on the pool, can overlap | reaper replacement must be reentrancy-safe | docs |

* Godot 4 (.NET)
| Fact | Consequence | Source |
|---+---+---|
| 4.0–4.3: net6.0. 4.4–4.7: net8.0 minimum, TFM may be raised; Android export needs .NET 9. 4.8 (dev): net10.0 | pin plan to net8.0; keep net9/10 in CI | =GodotSharp.csproj= per branch, docs |
| Scene tree is not thread-safe; use =CallDeferred=, =Callable.CallDeferred=, =Godot.Dispatcher.SynchronizationContext=; debug builds abort guarded calls from other threads with a printed error | eval that touches nodes must hop to the main thread | docs =thread_safe_apis= |
| =GodotSynchronizationContext=: =Post= enqueues, =Send= blocks the caller until the main thread drains the queue next frame; the whole queue is drained each frame with no time budget | =Send= from a session thread stalls the eval until next frame; a long eval on main stalls the frame | =GodotSynchronizationContext.cs= |
| =await ToSignal= resumes on the emitting thread (main) | usable as a hop primitive from C# | source |
| Editor loads the project assembly in a collectible =PluginLoadContext=; reload on assembly mtime change; unload is cooperative (=GC.Collect= loop); open issue #78513 "Failed to unload assemblies" since 2023 | background threads with frames in the game assembly, static refs, and dynamic assemblies created from game code block reload | =godot/modules/mono= |
| ClojureCLR emits =Run= (non-collectible) dynamic assemblies into the current contextual ALC or the caller's ALC | if =Clojure.dll= loads inside the collectible ALC, eval'd types pin it forever → host ClojureCLR + nREPL in =AssemblyLoadContext.Default= | =RuntimeAssemblyBuilder= docs |
| Exported game: collectible ALCs disabled; desktop = hostfxr/CoreCLR with =dotnet publish=; iOS = NativeAOT (no =Reflection.Emit= → no ClojureCLR eval); Android = Mono by default; Web = unsupported for C# | nREPL in exported desktop builds is fine; iOS/Web are out | =ExportPlugin.cs=, =iOS.props= |
| Godot is a native host: foreground managed threads do not keep the process alive | still set =IsBackground= for ALC hygiene | docs |
| =GD.Print= → native =print_line=; editor Output panel gets game output only via the remote debugger; =Console.Out= is separate | =forward-system-output= cannot see =GD.Print= without a Godot-side logger | =gd_mono= sources |
| In-process TCP listeners are allowed; macOS App Sandbox needs the network-server entitlement | | ArcadiaGodot precedent, Apple docs |
| No public Godot 4 + ClojureCLR project exists; ArcadiaGodot is Godot 3 Mono, last commit 2021 | this fork would be first | search |
